Antigravity Studio 是为 Antigravity（包括 IDE 编辑器、桌面端、终端 CLI 和 VS Code 插件）做的一款多账号管理与大模型代理工具。

平时用 Antigravity 写代码，账号多了换号麻烦，高频调用又容易撞上 429 限流，想用 DeepSeek、Claude 或本地模型也接不进来。这个工具就是为了解决这些日常痛点写的：把多个 Google 账号放到一个池子里自动调度，快清零的额度优先消耗，主号限流了备用号自动顶上；也可以把第三方的 API Key 放进来直接调用。所有操作都在本地完成，不经过任何第三方服务器。

## 它能解决什么问题？

日常用 Antigravity 编码，经常会碰到这些麻烦：

1. **配额用不完浪费，用得急又被限流**：Google 的免费配额每 5 小时滚动、每周重置，到期没用完就清零作废。写代码正投入时，单个号动不动就 429 限流，手头闲置的小号又用不上；换号得在几个工具里来回退出重登，很打断思路。
2. **多窗口并发抢号，响应变慢**：同时开几个项目写代码，请求全挤在一个号上容易被卡并发。如果切号切得随意，还会破坏服务端的上下文缓存（Prompt Cache），导致每次对话都要重新算一遍长上下文，首字回复特别慢。
3. **想在 Antigravity 里用其他大模型**：官方自带的模型种类有限，手里现成的 Claude、DeepSeek（带完整思考过程）、GPT 或本地 Ollama 没法直接用。
4. **聊几轮关键代码就被总结掉了**：官方默认的上下文压缩阈值偏低，多轮长对话聊着聊着，前面的关键实现和逻辑就被总结缩水了。
5. **历史对话到处分散，标题看不出内容**：在 IDE、独立端和终端 CLI 之间穿插干活，会话各存各的；默认生成的标题千篇一律，根本不知道之前聊的是哪个需求。
6. **本地端口被占导致代理打不开**：本地默认的 8321 端口偶尔会被其他程序占用，导致工具起不来。

## 核心功能

### 1. 多个账号自动轮换与接力
把多个 Google 账号加到池子里，工具会在本地代理层根据你选的策略自动分流：

- **故障转移（默认推荐）**：平时就用你登录的主号。一旦主号额度不足（默认低于 5%）或者被官方 429 限流，自动切到周额度最早清零的备用号接力；主号额度恢复或解除限流后，再自动切回来。要是池子里所有号都没额度了，会直接停下并提醒你，不会硬着头皮拿坏号报错。
- **重置优先**：主号和备用号一起排队。哪个号的周额度最先到期清零，就优先用哪个号，尽量在刷新前把快过期的免费额度榨干。
- **粘性会话**：每个对话窗口固定绑定一个账号。只要这个对话还在继续，就一直用同一个号，这样能充分利用服务端的上下文缓存，大幅减少等待时间；窗口里的子任务（Subagent）也会继承同一个号。遇到限流或额度用完时，才会帮你换到新号。
- **负载均衡**：把高频请求平均分发给各个健康账号，避免单号压力过大被限流。
- **额度警戒线与独立出网**：支持自己设置换号阈值（比如“额度低于 5% 换号”）；每个账号还可以单独挂不同的 HTTP / SOCKS5 代理，防止多个账号用同一个出口 IP 引起关联风控。

### 2. 自带 Key 接入任意模型（BYOK）
手里的第三方模型可以无缝接入 Antigravity：

- **内置 34+ 平台预设**：OpenAI、Anthropic、Gemini、DeepSeek、Ollama、OpenRouter、硅基流动、阿里云百炼、Kimi、智谱等，填上 API Key 就能用。
- **支持思考链与工具调用**：完整解析 DeepSeek 的思考过程（Thinking 流式输出），支持传图和调用代码工具（Tools）。
- **自定义上下文长度**：支持把模型的上下文窗口调大（比如 512K 或 1M），推迟官方过早总结的时机，长对话也不用担心丢代码。
- **纯本地直连**：填完 Key 可以一键测试连接。请求直接从你的电脑发给对应的服务商，中间没有任何第三方中转。

### 3. 一目了然的调度状态与大盘
不用猜当前请求走的是哪个号、为什么选它：

- **大白话调度情报**：主界面底栏会直接显示当前调度的原因，比如“来自 Antigravity IDE 的会话 · 分配至备用号：主号配额低于 5%，由备用号接管”，耗时、Token 消耗和缓存命中率一清二楚。
- **服务状态边框**：正在回复的卡片会有流光提示，并且会按模型（Gemini 蓝紫色、Claude 橙红色等）区分颜色，AI 回复完自然熄灭。
- **端口冲突自动顺延**：如果默认的 8321 端口被其他软件占了，工具会自动往后尝试其他可用端口（如 8322），主界面还会弹出提示，点击一下就能把各个编辑器的配置同步过去。

---

### 4. 一键接管编辑器与安全切号
- **自动识别多种客户端**：自动检测本机的 Antigravity 2.0 桌面端、Antigravity IDE、VS Code 插件和终端命令行 CLI。
- **一键开关代理**：在界面上点一下就能给对应的客户端开启代理，命令行还提供了一键启动命令；不想用的时候随时点一下恢复官方直连，完全不改动官方安装文件。
- **安全切号防冲突**：切换登录账号时，工具会在后台做好安全加锁与文件备份，防止编辑器配置文件被写坏。

---

### 5. 跨端会话整理与 AI 智能起名
- **统一找回历史对话**：集中浏览 IDE、独立端、CLI 和 VS Code 里的所有历史对话，支持按项目、客户端筛选和搜索。
- **AI 读完全文帮忙起名**：默认标题看不懂时，点一下就能让 AI 读完整场对话，总结出一个意思精准的短标题，还支持挑几个备选。
- **保护隐私**：会话内容完全由对应的编辑器本地打开查看，工具本身只做索引和管理。

- **算清用量与花费**：按天、按周统计 Token 消耗、调用次数，还能看普通输入、模型输出、思考过程 Token 分布，以及估算的花费。

```text

                     │
                     ▼ (本地请求发往代理端口)
              本地代理服务 (默认 8321，被占自动顺延)
                     │
         ┌───────────┴───────────┐
         ▼                       ▼
   官方模型请求 (Gemini / Claude)   第三方模型请求 (BYOK)
         │                       │
         ▼                       ▼ (本地协议转换 / 思维链解析)
  智能账号池调度                  DeepSeek / OpenAI / Claude / Ollama
  (故障转移 / 重置优先 / 粘性会话)
         │
         ▼ (每个号可走独立代理)
   Google 官方服务器
```

### 1. 下载安装包

到 [GitHub Releases](https://github.com/yuzhiqiang1993/antigravity-studio/releases/latest) 下载适合自己系统的安装包：

| 系统平台 | 安装包 | 适合机型 |
| :--- | :--- | :--- |
| **macOS (Apple Silicon)** | `Antigravity-Studio-x.x.x-macos-arm64.dmg` | M1 / M2 / M3 / M4 等芯片的 Mac |
| **macOS (Intel)** | `Antigravity-Studio-x.x.x-macos-x64.dmg` | Intel 处理器的 Mac |
| **Windows (x64)** | `Antigravity-Studio-x.x.x-windows-x64.exe` | 64 位 Windows 10 / 11 |

> **macOS 打开提示“已损坏”或“无法打开”？**
> 这是系统拦截了未签名的开源软件。打开系统自带的「终端」，复制执行这条命令即可：
> ```bash
> sudo xattr -rd com.apple.quarantine "/Applications/Antigravity Studio.app"
> ```

### 2. 上手步骤

1. **添加账号或模型**：
   - 官方模型：在「账号」页登录或导入多个 Google 账号，打开调度开关，选好策略（推荐用“故障转移”）；
   - 第三方模型：在「模型」页点「添加服务商」，选好平台填入 API Key，勾选想用的模型。
2. **开启代理接管**：在「概览」页找到你的编辑器（比如 Antigravity IDE），把开关拨到开启；用终端 CLI 的话，复制命令启动即可。
3. **正常写代码**：打开编辑器，在模型列表里就能看到新加的模型了。调用官方模型时，后台会自动挑最合适的账号提供服务。

## 常见问题

**Q: 自动换号会影响我正在写的代码吗？**
- 不会。如果用「粘性会话」，当前对话会一直锁定同一个账号，保住上下文缓存；如果用「故障转移」，主号正常时不会切号，只有主号额度不足或被限流时才由备用号接上。要是池子里所有号都没额度了，会直接停下提醒，不会拿坏号硬跑。

**Q: “重置优先”为什么能防浪费？**
- Google 的配额到期没用完就作废了。“重置优先”会看着每个号的倒计时，哪个号最早清零就先用哪个，帮你在额度刷新前多用一点。

**Q: 换号阈值是什么意思？**
- 就是“额度低于多少时换号”（默认 5%）。当某个号 5 小时内的剩余额度掉到 5% 以下时，系统就认为它不够用了，自动找合格的号顶上。

**Q: 每个账号可以挂不同的代理吗？**
- 可以。在账号卡片上可以给每个号单配 HTTP 或 SOCKS5 代理。连带着刷新 Token、查配额和发请求都走各自的代理通道，避免多个号挤在同一个出口 IP 上。

**Q: 默认的 8321 端口被其他软件占了怎么办？**
- 工具会自动往后找空闲端口（比如 8322）。首页也会弹出黄色横幅，点一下“一键修复”就能把编辑器的配置自动改过去，不用手动折腾。

**Q: 开启代理后，编辑器里没看到新模型？**
- 先看「模型」页里有没有勾选这个模型；
- 看「概览」页里代理是不是绿色的运行中，编辑器卡片是不是显示“已接入”；
- 把编辑器彻底退掉重启一次，让它重新读一下配置。

**Q: 关掉代理或还原直连，我的配置会丢吗？**
- 不会。关掉代理只是把编辑器的网络指回官方，保存的账号、Key、模型和用量数据都在你的电脑里。

**Q: 我的 Key、账号和代码安全吗？**
- 安全。Antigravity Studio 是完全开源的本地软件，没有后门也没有云端中转服务器。所有凭据只存放在你本地，请求直接从本机发给 Google 或你配置的模型服务商。
